# M4, part 1: The World — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Characters enter one shared scene, move, see each other and chat, and admins get `!` commands, all with the real client. This is M4's first piece (world spec §1).

**Architecture:**
- A headless bevy_ecs world runs on its own thread at `[server] tick_hz`.
- The gate's connection tasks feed it protocol-neutral events (`WorldIn`), and each gets the world's answers (`WorldOut`) on a bounded channel of its own.
- `fenji-proto`'s world codecs, written from the exe reading, map these events to and from the wire.
- Saves and invites run off the tick, on the tokio runtime.

**Tech stack:**
- Rust 1.97.1, edition 2024.
- bevy_ecs 0.20.0, the latest Bevy major (released 2026-10-08), with `std` as its only feature: schedules run single-threaded on the world's own thread.
- tokio 1.53 and sqlx 0.9 (SQLite).
- The workspace's own `fenji-proto`, `fenji-store` and `fenji-server`.

**Spec:** [`docs/superpowers/specs/2026-10-13-m4-world-design.md`](../specs/2026-10-13-m4-world-design.md).
- Its parents are the [M4 spec](../specs/2026-10-13-m4-social-sandbox-design.md) and the [Fenji design spec](../specs/2026-10-11-fenji-design.md) (§6.4–6.7, §9).
- This plan's pull request corrects the world spec's §3.2 ([Corrections to the spec](#corrections-to-the-spec)).

## Global Constraints

- **Ground rules.** Ground rules 1–7 (CLAUDE.md) bind every task. A step that would patch the client, attach a debugger, load its AGT driver or get around a protection stops for the owner (ground rule 6): file a `Decision gate` issue and wait.
- **Lanes.**
  - **Local** tasks need the client: the shared Ghidra project, REA, the survey notes in `re/m4/world-survey/`, and client runs.
  - **Cloud** tasks need only the public repository.
  - Nothing from `re/`, `$FENJI_CLIENT_PATH`, captures or run logs goes into a cloud brief.
- **Cloud agents** are Opus 5.5 at max effort: the Agent tool with `isolation: "remote"`, `model: "opus"` and `effort: "max"`, every time.
- **No session links** in commits, pull request bodies or tracked files.
  - Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and nothing else.
  - Pull request bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)` and nothing else.
  - `scripts/check-no-session-links.sh` and CI refuse anything more.
- **Staging.** Stage files by path, never with `git add -A`. Never stage `.claude/settings.json`.
- **Commits and pull requests.**
  - Conventional Commits with the repository's scopes.
  - Commit subjects of at most 100 characters, pull request titles of at most 93.
  - One pull request per concern, with `Closes #N`, squash-merged into `dev` once CI is green and the task's review is clean.
- **Branches** come from `dev` and are named for the task's issue: `feat/<scope>-<issue>-<topic>`.
- **Bevy.** `bevy_ecs = { version = "0.20.0", default-features = false, features = ["std"] }`. No Events, Messages or observers: a tick's inputs wait in resources.
- **Never sent** from Task 1 on: 556, 243, 216, 627, 729, 720, 598, 68, 714, 374, 50 and 616 (`fenji_proto::packet::NEVER_SEND`; Task 1 found the last three). Every script message the world sends goes through the gate's `script_out`.
- **Level.** Characters are created at level 37 (`fenji_store::CREATE_LEVEL`), and the migration raises M3's characters to 37.
- **The default meeting scene** is `[world] start_scene = 5` at `start_position = [2366.0, -71735.0, 64854.0, 345.0]`. That is the start point of vocations 0–5 in the client's tables (Inferred), until Task 11's runs verify or replace it.
- **Positions.**
  - Positions are in the client's units (centimetres, Inferred), with z up and the yaw in degrees within ±360.
  - The interest grid's cells are 5,000 units, and a player sees the 3×3 cells around it in its scene.
- **The speed rule.**
  - Rate 100 is 500 units/s.
  - The check allows a sprint (×1.7) times `[world] move_tolerance` (default 1.5, 1.0 to 5.0), with at most a second's worth saved up.
  - Climbing counts; falling doesn't.
- **Chat.**
  - 140 characters as the client counts them, and 2,048 bytes.
  - A burst of 5 lines, then one a second.
  - Channels 0, 1 and 5 only.
  - Exactly the three entities the client writes, `&amp;`, `&lt;` and `&gt;`.
  - No backslash, and a `[` only before a digit or `]`.
  - No controls or invisible formatting.
- **Saves** happen when a character leaves, every `[world] save_every_secs` (default 300, 30 to 3600), and for everyone at shutdown. Never inside a tick.
- **The tick.**
  - `[server] tick_hz`, default 20, 1 to 60.
  - The target is p99 tick work of at most 10 ms with 20 players (design spec §6.7).
  - A tick over its budget is logged with its slowest phase.
- **Actor ids.** A player's actor id is its pid, which must be in 1..2⁴⁸.
- **Test-first.** Every code change follows superpowers:test-driven-development. Before every pull request: `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace && cargo deny check`.
- **Evidence.**
  - REA Evidence IDs, or pinned-exe addresses where REA can't reach, go in `docs/protocol/` and in codec doc comments.
  - Observed, Inferred and Unknown are kept apart.
  - Close every REA session. Never use Ghidra's `debugger_*` tools.
- **Client runs.**
  - Only through `scripts/spike/run-client.sh` (the sandbox, nested display :99) or `run-bare.sh` (the Linux game box under the owner's guards, never `--gf-sdk=mocked`).
  - Never with Steam running.
  - The run's prediction is written before it starts.
  - A watchdog exit 3 stops all runs for a write-up. M2's rule: runs continue only on a proven non-AGT false positive.

## Review Focus

These are the five inputs most likely to hurt players that the spec implies but doesn't spell out. Each has its tests in the task that owns the code.

1. **A connection that ends at any moment in the world:** the socket closes while loading, an idle timeout, `CLIENT_EXIT`, a kick.
   - Everyone who knew of the player hears it left (9).
   - Its place is saved, and no index or view keeps it.
   - Tests: Task 4 `leaving_saves_the_place_and_forgets_the_player`; Task 5 `whoever_knew_of_a_player_hears_it_left_however_it_left`; Task 11, a socket closed mid-load.
2. **A second login while the account is in the world.**
   - The old actor leaves (saved, 9 to its viewers) before the new one joins.
   - The same character comes back where it stood, not where the store last saved it.
   - Tests: Task 4 `a_newer_login_replaces_the_account_and_keeps_where_it_stood`; Task 5 `a_replaced_player_is_seen_again_where_it_stood_once_its_new_client_loads`; Task 11, two logins through the gate.
3. **Hostile movement:** NaN, infinite or far-out coordinates, a yaw past 360, time going back, many moves in one tick, a climb.
   - The actor never moves past the speed rule, nothing panics, and a refused move reaches no one.
   - A relay is built from the checked position and the decoder's bounded fields, never from the client's bytes.
   - Tests: Task 6 `hostile_points_and_times_fail_without_harm`, `climbing_counts_and_falling_does_not` and `a_burst_after_a_stall_passes_and_hostile_moves_never_reach_others`; Task 15, relays re-encoded.
4. **Chat that tries to be something else:** link or sound markup, stray entities, backslash escapes, controls, bidirectional overrides and other invisible formatting, over-long lines.
   - Nothing can forge a sender, a GM badge or a system line, in players' clients or in a host's terminal.
   - Tests: Task 7 `the_client_limits_hold_and_markup_is_refused` and `a_forged_line_or_a_sixth_in_a_second_is_refused_and_reaches_no_one`; Task 8, command text that isn't plain.
5. **A client that stops reading, or floods.** The tick never waits.
   - A full outbound channel kicks the client.
   - So do more than `MAX_INPUTS_PER_TICK` messages in one tick.
   - Tests: Task 4 `a_client_that_stops_reading_is_kicked_without_stalling_the_tick` and `a_flood_is_kicked`; Task 11, the link's channel and write deadline.

## Corrections to the spec

This plan's pull request corrects the world spec's §3.2, by the owner's decision of 2026-10-13 (#180).
- **Why.** A host's server can't read the client's design tables: they are Oodle-compressed in the archives. So the outfit can't be read from `[data] client_path`.
- **The outfit's source.** The outfit comes from a table of item ids that Fenji ships, documented with evidence in `docs/protocol/`. If Task 10's reading shows the client fills in the outfit itself from `prop_base_equips_id`, Fenji sends that and ships no ids.
- **No outfit column.** The store gains no outfit column: until M5 gives characters their own equipment, the outfit follows from the vocation and the outfit choice already stored.

use sqlx::sqlite::SqliteRow;
use sqlx::{FromRow, Row};

use crate::error::is_unique;
use crate::{Error, Result, Store};

/// The level characters are created at: the client's `CreateLv`, which their starting weapons
/// need (M4 world spec §2.5).
pub const CREATE_LEVEL: i64 = 37;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct NewCharacter {
    pub name: String,
    pub vocation: i64,
    pub skeleton: i64,
    /// The appearance fields, as the server encodes them (M3 spec D8).
    pub appearance: Vec<u8>,
}

/// Where a character stands (M4 world spec §3.2): a scene, a point (z is up) and a yaw in degrees.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Place {
    pub scene: i64,
    pub x: f64,
    pub y: f64,
    pub z: f64,
    pub yaw: f64,
}

#[derive(Debug, Clone, PartialEq)]
pub struct Character {
    pub pid: i64,
    pub account_id: i64,
    pub name: String,
    pub vocation: i64,
    pub skeleton: i64,
    pub level: i64,
    pub appearance: Vec<u8>,
    pub created_at: i64,
    /// Where it last stood in the world; `None` until it first enters.
    pub place: Option<Place>,
}

/// The columns a [`Character`] is read from, as a literal for `concat!`: sqlx takes only static
/// SQL.
macro_rules! columns {
    () => {
        "pid, account_id, name, vocation, skeleton, level, appearance, created_at, \
         scene, pos_x, pos_y, pos_z, yaw"
    };
}

impl FromRow<'_, SqliteRow> for Character {
    fn from_row(row: &SqliteRow) -> sqlx::Result<Self> {
        let scene: Option<i64> = row.try_get("scene")?;
        let point: (Option<f64>, Option<f64>, Option<f64>, Option<f64>) = (
            row.try_get("pos_x")?,
            row.try_get("pos_y")?,
            row.try_get("pos_z")?,
            row.try_get("yaw")?,
        );
        let place = match (scene, point) {
            (Some(scene), (Some(x), Some(y), Some(z), Some(yaw))) => Some(Place {
                scene,
                x,
                y,
                z,
                yaw,
            }),
            _ => None,
        };
        Ok(Self {
            pid: row.try_get("pid")?,
            account_id: row.try_get("account_id")?,
            name: row.try_get("name")?,
            vocation: row.try_get("vocation")?,
            skeleton: row.try_get("skeleton")?,
            level: row.try_get("level")?,
            appearance: row.try_get("appearance")?,
            created_at: row.try_get("created_at")?,
            place,
        })
    }
}

impl Store {
    /// The account's characters, oldest first.
    pub async fn list_characters(&self, account_id: i64) -> Result<Vec<Character>> {
        Ok(sqlx::query_as(concat!(
            "SELECT ",
            columns!(),
            " FROM characters WHERE account_id = ? ORDER BY pid"
        ))
        .bind(account_id)
        .fetch_all(&self.pool)
        .await?)
    }

    /// The character `pid`, only if it belongs to `account_id`.
    pub async fn character(&self, account_id: i64, pid: i64) -> Result<Option<Character>> {
        Ok(sqlx::query_as(concat!(
            "SELECT ",
            columns!(),
            " FROM characters WHERE pid = ? AND account_id = ?"
        ))
        .bind(pid)
        .bind(account_id)
        .fetch_optional(&self.pool)
        .await?)
    }

    /// Creates a character at [`CREATE_LEVEL`], with no place yet. The account's limit and the
    /// name check run in the same transaction as the insert.
    pub async fn create_character(
        &self,
        account_id: i64,
        new: &NewCharacter,
        max_per_account: u32,
        now: i64,
    ) -> Result<Character> {
        let mut tx = self.begin().await?;
        let (count,): (i64,) =
            sqlx::query_as("SELECT COUNT(*) FROM characters WHERE account_id = ?")
                .bind(account_id)
                .fetch_one(&mut *tx)
                .await?;
        if count >= i64::from(max_per_account) {
            return Err(Error::TooMany);
        }
        let inserted = sqlx::query_as(concat!(
            "INSERT INTO characters \
             (account_id, name, vocation, skeleton, level, appearance, created_at) \
             VALUES (?, ?, ?, ?, ?, ?, ?) RETURNING ",
            columns!()
        ))
        .bind(account_id)
        .bind(&new.name)
        .bind(new.vocation)
        .bind(new.skeleton)
        .bind(CREATE_LEVEL)
        .bind(&new.appearance)
        .bind(now)
        .fetch_one(&mut *tx)
        .await;
        let c: Character = match inserted {
            Ok(c) => c,
            Err(e) if is_unique(&e) => return Err(Error::NameTaken),
            Err(e) => return Err(e.into()),
        };
        tx.commit().await?;
        Ok(c)
    }

    /// Saves where `pid` stands, in one statement. False when the character is gone (deleted
    /// while its player was in the world). SQLite would store a NaN as null and lose the place,
    /// so a place that isn't finite is refused.
    pub async fn save_place(&self, pid: i64, place: &Place) -> Result<bool> {
        if ![place.x, place.y, place.z, place.yaw]
            .iter()
            .all(|v| v.is_finite())
        {
            return Err(Error::NotFinite);
        }
        let r = sqlx::query(
            "UPDATE characters SET scene = ?, pos_x = ?, pos_y = ?, pos_z = ?, yaw = ? \
             WHERE pid = ?",
        )
        .bind(place.scene)
        .bind(place.x)
        .bind(place.y)
        .bind(place.z)
        .bind(place.yaw)
        .bind(pid)
        .execute(&self.pool)
        .await?;
        Ok(r.rows_affected() == 1)
    }

    /// Deletes `pid` only if it belongs to `account_id`.
    pub async fn delete_character(&self, account_id: i64, pid: i64) -> Result<bool> {
        let r = sqlx::query("DELETE FROM characters WHERE pid = ? AND account_id = ?")
            .bind(pid)
            .bind(account_id)
            .execute(&self.pool)
            .await?;
        Ok(r.rows_affected() == 1)
    }
}

## Task 4 [cloud]: The world's core: the ECS, its tick thread and its saves

The world as M4 world spec §3.9 sets it out, with the phases that need nothing from the wire: taking players in, loading, leaving, kicking, periodic saves and shutdown.
- **Later phases.** Pulls, moves and chat lines are counted against the flood limit; their phases come in Tasks 5–7.
- **No outbound phase.** The spec's list of systems ends with "outbound". Here each phase sends as it goes, with a non-blocking `try_send` (`send` in exclusive code, `deliver` in systems), which is what an outbound phase would do at the end of the tick. A full channel dooms its player, and the cleanup phase takes the doomed out; with the persist phase, that is the "mark dirty" role.
- **The interface is fixed now.** `types.rs` fixes the whole protocol-neutral interface, so the local slices can write the link against it while Tasks 5–8 run.

    pub struct Harness {
        pub core: WorldCore,
        pub services: mpsc::UnboundedReceiver<Service>,
        pub now: u64,
        outs: HashMap<ConnId, mpsc::Receiver<WorldOut>>,
        queued: Vec<WorldIn>,
    }

    impl Harness {
        pub fn new() -> Self {
            Self::with(rules())
        }

        pub fn with(rules: Rules) -> Self {
            let (tx, rx) = mpsc::unbounded_channel();
            Self {
                core: WorldCore::new(rules, tx),
                services: rx,
                now: 1_000,
                outs: HashMap::new(),
                queued: Vec::new(),
            }
        }

        /// Queues a join with an outbound channel of `capacity`.
        pub fn join_with(&mut self, player: Player, capacity: usize) {
            let (tx, rx) = mpsc::channel(capacity);
            self.outs.insert(player.conn, rx);
            self.queued.push(WorldIn::Join { player, out: tx });
        }

        pub fn join(&mut self, player: Player) {
            self.join_with(player, 256);
        }

        pub fn push(&mut self, input: WorldIn) {
            self.queued.push(input);
        }

        /// Runs a tick `ms` after the last one, with what was queued.
        pub fn tick(&mut self, ms: u64) {
            self.now += ms;
            let inputs = std::mem::take(&mut self.queued);
            self.core.step(self.now, inputs);
        }

        /// What `conn` was sent since the last call.
        pub fn take(&mut self, conn: ConnId) -> Vec<WorldOut> {
            let rx = self.outs.get_mut(&conn).expect("a joined connection");
            let mut out = Vec::new();
            while let Ok(m) = rx.try_recv() {
                out.push(m);
            }
            out
        }

        /// Whether `conn`'s channel has closed: the world let go of it.
        pub fn closed(&mut self, conn: ConnId) -> bool {
            let rx = self.outs.get_mut(&conn).expect("a joined connection");
            matches!(rx.try_recv(), Err(mpsc::error::TryRecvError::Disconnected))
        }

        /// The services work queued since the last call.
        pub fn saves(&mut self) -> Vec<Service> {
            let mut out = Vec::new();
            while let Ok(s) = self.services.try_recv() {
                out.push(s);
            }
            out
        }

        /// Joins `player`, loads it and empties its channel: it stands in the world.
        pub fn enter(&mut self, player: Player) {
            let conn = player.conn;
            self.join(player);
            self.push(WorldIn::Loaded { conn });
            self.tick(50);
            self.take(conn);
        }
    }

    pub y: f64,

//! The world's ECS (M4 world spec §3.9; Fenji design spec §6.4): one bevy_ecs `World` with an
//! entity per player in the game. A tick runs its phases in order, each its own `Schedule`, so a
//! slow tick can name its slowest phase.
use std::collections::HashMap;
use std::time::{Duration, Instant};

use bevy_ecs::prelude::*;
use bevy_ecs::system::ScheduleSystem;
use tokio::sync::mpsc;
use tokio::sync::mpsc::error::TrySendError;

use super::types::*;

/// The world's settings, from fenji.toml.
#[derive(Debug, Clone, Resource)]
pub struct Rules {
    /// Ticks per second (`[server] tick_hz`).
    pub tick_hz: u32,
    /// The speed check's leniency (`[world] move_tolerance`).
    pub move_tolerance: f64,
    /// How often everyone's place is saved, in milliseconds (`[world] save_every_secs`).
    pub save_every_ms: u64,
    /// The most messages a connection may send in one tick; one more and it is kicked.
    pub max_inputs_per_tick: usize,
}

/// A player's connection.
#[derive(Component)]
pub(super) struct Conn {
    pub id: ConnId,
    pub out: mpsc::Sender<WorldOut>,
}

/// The account a player belongs to.
#[derive(Component)]
pub(super) struct Account {
    pub id: i64,
}

/// The character: its pid, and what others see.
#[derive(Component)]
pub(super) struct Actor {
    pub pid: ActorId,
    pub look: Look,
}

/// Where the player stands.
#[derive(Component, Clone, Copy)]
pub(super) struct Here(pub Location);

/// Whether the player's client has loaded its scene.
#[derive(Component, Clone, Copy, PartialEq, Eq, Debug)]
pub(super) enum Stage {
    Loading,
    InWorld,
}

/// Leaves at the end of the tick. The reason, if any, goes to its connection.
#[derive(Component, Clone, Copy)]
pub(super) struct Doomed(pub Option<KickReason>);

/// The tick's time, in milliseconds of a monotonic clock.
#[derive(Resource, Default)]
pub(super) struct Now(pub u64);

#[derive(Resource, Default)]
struct Inbox(Vec<WorldIn>);

/// Players by connection, pid, account and name (as [`name_key`] folds it).
#[derive(Resource, Default)]
pub(super) struct Index {
    pub conns: HashMap<ConnId, Entity>,
    pub pids: HashMap<ActorId, Entity>,
    pub accounts: HashMap<i64, Entity>,
    pub names: HashMap<String, Entity>,
}

/// The services task's channel.
#[derive(Resource)]
pub(super) struct Services(pub mpsc::UnboundedSender<Service>);

/// When everyone's place is next saved; set by the first tick.
#[derive(Resource, Default)]
struct NextSave(Option<u64>);

/// The world: its ECS, and the phases a tick runs.
pub struct WorldCore {
    world: World,
    phases: Vec<(&'static str, Schedule)>,
}

fn phase<M>(systems: impl IntoScheduleConfigs<ScheduleSystem, M>) -> Schedule {
    let mut schedule = Schedule::default();
    schedule.add_systems(systems);
    schedule
}

impl WorldCore {
    pub fn new(rules: Rules, services: mpsc::UnboundedSender<Service>) -> Self {
        let mut world = World::new();
        world.insert_resource(NextSave::default());
        world.insert_resource(rules);
        world.insert_resource(Now::default());
        world.insert_resource(Inbox::default());
        world.insert_resource(Index::default());
        world.insert_resource(Services(services));
        let phases = vec![
            ("inbound", phase(inbound)),
            ("persist", phase(persist)),
            ("cleanup", phase(cleanup)),
        ];
        Self { world, phases }
    }

    /// Runs one tick at `now_ms`, with what arrived since the last one in arrival order, and
    /// returns how long each phase took.
    pub fn step(&mut self, now_ms: u64, inputs: Vec<WorldIn>) -> Vec<(&'static str, Duration)> {
        self.world.resource_mut::<Now>().0 = now_ms;
        self.world.resource_mut::<Inbox>().0 = inputs;
        self.phases
            .iter_mut()
            .map(|(name, schedule)| {
                let began = Instant::now();
                schedule.run(&mut self.world);
                (*name, began.elapsed())
            })
            .collect()
    }

    /// The players in the world, loading or not.
    pub fn players(&self) -> usize {
        self.world.resource::<Index>().conns.len()
    }
}

/// A name as the index keeps it. Names are unique without regard to ASCII case, as the store's
/// `COLLATE NOCASE` compares them.
pub(super) fn name_key(name: &str) -> String {
    name.to_ascii_lowercase()
}

/// Applies the tick's inputs in arrival order. A connection that sends more than
/// `max_inputs_per_tick` is kicked.
fn inbound(world: &mut World) {
    let inputs = std::mem::take(&mut world.resource_mut::<Inbox>().0);
    let max = world.resource::<Rules>().max_inputs_per_tick;
    let mut counts: HashMap<ConnId, usize> = HashMap::new();
    for input in inputs {
        match input {
            WorldIn::Join { player, out } => join(world, player, out),
            WorldIn::Leave { conn } => {
                if let Some(e) = live(world, conn) {
                    doom(world, e, None);
                }
            }
            WorldIn::Shutdown => {
                let all: Vec<Entity> = world.resource::<Index>().conns.values().copied().collect();
                for e in all {
                    doom(world, e, Some(KickReason::Shutdown));
                }
            }
            WorldIn::Tell { conn, text } => {
                if let Some(e) = live(world, conn) {
                    send(world, e, WorldOut::Chat(ChatOut::System { text }));
                }
            }
            WorldIn::Loaded { conn } => {
                if let Some(e) = counted(world, &mut counts, max, conn) {
                    loaded(world, e);
                }
            }
            // Counted against the limit; the phases that take them come with interest, movement
            // and chat.
            WorldIn::Pull { conn, .. }
            | WorldIn::Move { conn, .. }
            | WorldIn::Chat { conn, .. } => {
                counted(world, &mut counts, max, conn);
            }
        }
    }
}

/// The connection's player, unless it leaves this tick.
pub(super) fn live(world: &World, conn: ConnId) -> Option<Entity> {
    let e = *world.resource::<Index>().conns.get(&conn)?;
    world.get::<Doomed>(e).is_none().then_some(e)
}

/// [`live`], counting the message against the connection's limit for the tick.
fn counted(
    world: &mut World,
    counts: &mut HashMap<ConnId, usize>,
    max: usize,
    conn: ConnId,
) -> Option<Entity> {
    let e = live(world, conn)?;
    let n = counts.entry(conn).or_insert(0);
    *n += 1;
    if *n > max {
        doom(world, e, Some(KickReason::Flood));
        return None;
    }
    Some(e)
}

/// A character enters. An account already in the game is replaced, and the same character keeps
/// where it stood, which may be newer than the store's copy.
fn join(world: &mut World, player: Player, out: mpsc::Sender<WorldOut>) {
    if !(1..=MAX_PLAYER_ID).contains(&player.pid) {
        // The connection side refuses these first; a bad id never gets an actor.
        let _ = out.try_send(WorldOut::Kicked(KickReason::Kicked));
        return;
    }
    let mut at = player.at;
    let older = world
        .resource::<Index>()
        .accounts
        .get(&player.account)
        .copied();
    if let Some(old) = older {
        if world.get::<Actor>(old).is_some_and(|a| a.pid == player.pid)
            && let Some(here) = world.get::<Here>(old)
        {
            at = here.0;
        }
        remove(world, old, Some(KickReason::Replaced));
    }
    let name = name_key(&player.look.name);
    let e = world
        .spawn((
            Conn {
                id: player.conn,
                out,
            },
            Account { id: player.account },
            Actor {
                pid: player.pid,
                look: player.look,
            },
            Here(at),
            Stage::Loading,
        ))
        .id();
    let mut index = world.resource_mut::<Index>();
    index.conns.insert(player.conn, e);
    index.pids.insert(player.pid, e);
    index.accounts.insert(player.account, e);
    index.names.insert(name, e);
    send(
        world,
        e,
        WorldOut::LoadScene {
            pid: player.pid,
            at,
        },
    );
}

/// The client has loaded its scene: it gets its own actor. A repeated report changes nothing.
fn loaded(world: &mut World, e: Entity) {
    if world.get::<Stage>(e) != Some(&Stage::Loading) {
        return;
    }
    let (Some(actor), Some(here)) = (world.get::<Actor>(e), world.get::<Here>(e)) else {
        return;
    };
    let msg = WorldOut::SelfEnter {
        pid: actor.pid,
        look: actor.look.clone(),
        pos: here.0.pos,
        speed: SPEED_RATE,
    };
    if let Some(mut stage) = world.get_mut::<Stage>(e) {
        *stage = Stage::InWorld;
    }
    send(world, e, msg);
}

/// Sends `msg` to `e`'s connection. A full channel means its client stopped reading, so it is
/// kicked; a closed one means the connection has gone, so it leaves.
pub(super) fn send(world: &mut World, e: Entity, msg: WorldOut) {
    let Some(conn) = world.get::<Conn>(e) else {
        return;
    };
    match conn.out.try_send(msg) {
        Ok(()) => {}
        Err(TrySendError::Full(_)) => doom(world, e, Some(KickReason::SlowReader)),
        Err(TrySendError::Closed(_)) => doom(world, e, None),
    }
}

/// Marks `e` to leave at the end of the tick. The first reason stands.
pub(super) fn doom(world: &mut World, e: Entity, reason: Option<KickReason>) {
    if let Ok(mut entity) = world.get_entity_mut(e)
        && !entity.contains::<Doomed>()
    {
        entity.insert(Doomed(reason));
    }
}

/// Takes `e` out of the game now: its place is saved, its connection hears why when there is a
/// reason, and the index forgets it.
fn remove(world: &mut World, e: Entity, reason: Option<KickReason>) {
    let (Some(actor), Some(here), Some(conn), Some(account)) = (
        world.get::<Actor>(e),
        world.get::<Here>(e),
        world.get::<Conn>(e),
        world.get::<Account>(e),
    ) else {
        world.despawn(e);
        return;
    };
    let (pid, at, conn_id, account_id) = (actor.pid, here.0, conn.id, account.id);
    let name = name_key(&actor.look.name);
    if let Some(reason) = reason {
        let _ = conn.out.try_send(WorldOut::Kicked(reason));
    }
    let _ = world
        .resource::<Services>()
        .0
        .send(Service::SavePlace { pid, at });
    world.despawn(e);
    let mut index = world.resource_mut::<Index>();
    unindex(&mut index.conns, &conn_id, e);
    unindex(&mut index.pids, &pid, e);
    unindex(&mut index.accounts, &account_id, e);
    unindex(&mut index.names, &name, e);
}

/// Removes `key` from `map` only if it still names `e`.
fn unindex<K: std::hash::Hash + Eq>(map: &mut HashMap<K, Entity>, key: &K, e: Entity) {
    if map.get(key) == Some(&e) {
        map.remove(key);
    }
}

/// Every `save_every_ms`, saves where everyone stands.
fn persist(
    now: Res<Now>,
    rules: Res<Rules>,
    mut next: ResMut<NextSave>,
    players: Query<(&Actor, &Here)>,
    services: Res<Services>,
) {
    let due = now.0.saturating_add(rules.save_every_ms);
    match next.0 {
        Some(at) if now.0 >= at => next.0 = Some(due),
        Some(_) => return,
        None => {
            next.0 = Some(due);
            return;
        }
    }
    for (actor, here) in &players {
        let _ = services.0.send(Service::SavePlace {
            pid: actor.pid,
            at: here.0,
        });
    }
}

/// Takes the doomed players out. Telling their viewers can doom more (a full channel), so it goes
/// on until none is left.
fn cleanup(world: &mut World) {
    loop {
        let mut doomed = world.query::<(Entity, &Doomed)>();
        let out: Vec<(Entity, Option<KickReason>)> =
            doomed.iter(world).map(|(e, d)| (e, d.0)).collect();
        if out.is_empty() {
            return;
        }
        for (e, reason) in out {
            remove(world, e, reason);
        }
    }
}

//! The world's thread (Fenji design spec §6.4, §6.7). It ticks at `tick_hz`, takes in what arrived
//! since the last tick, and keeps the last minute of tick times. A tick over its budget is logged
//! with its slowest phase, at most once every 10 seconds.

use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

use fenji_store::Store;

/// How long stopping waits for the last saves (Fenji design spec §6.7: 20 characters in 2 s).

/// How connections reach the world. Clones share the channel.
#[derive(Clone)]
pub struct WorldHandle(mpsc::UnboundedSender<WorldIn>);

impl WorldHandle {
    /// Sends `msg` to the world. False once the world has stopped.
    pub fn send(&self, msg: WorldIn) -> bool {
        self.0.send(msg).is_ok()
    }

/// Tick work over the last minute.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct TickReport {
    /// Ticks since the world started.
    pub ticks: u64,
    pub p50: Duration,
    pub p99: Duration,
    pub max: Duration,
    /// Ticks since the start whose work took longer than a tick.
    pub over_budget: u64,
}

struct Stats {
    window: VecDeque<Duration>,
    size: usize,
    ticks: u64,
    over: u64,
    warned: Option<Instant>,
}

impl Stats {
    fn new(size: usize) -> Self {
        Self {
            window: VecDeque::with_capacity(size),
            size,
            ticks: 0,
            over: 0,
            warned: None,
        }
    }

    fn record(&mut self, work: Duration, phases: &[(&'static str, Duration)], budget: Duration) {
        self.ticks += 1;
        if self.window.len() == self.size {
            self.window.pop_front();
        }
        self.window.push_back(work);
        if work <= budget {
            return;
        }
        self.over += 1;
        if self
            .warned
            .is_some_and(|t| t.elapsed() < Duration::from_secs(10))
        {
            return;
        }
        self.warned = Some(Instant::now());
        let (slowest, took) = phases
            .iter()
            .copied()
            .max_by_key(|(_, d)| *d)
            .unwrap_or(("none", Duration::ZERO));
        tracing::warn!(
            work_ms = work.as_millis() as u64,
            budget_ms = budget.as_millis() as u64,
            slowest,
            slowest_ms = took.as_millis() as u64,
            over_budget = self.over,
            "a world tick ran over its budget"
        );
    }

    fn report(&self) -> TickReport {
        let mut sorted: Vec<Duration> = self.window.iter().copied().collect();
        sorted.sort();
        let at = |q: f64| {
            let i = (sorted.len().saturating_sub(1) as f64 * q).round() as usize;
            sorted.get(i).copied().unwrap_or_default()
        };
        TickReport {
            ticks: self.ticks,
            p50: at(0.5),
            p99: at(0.99),
            max: sorted.last().copied().unwrap_or_default(),
            over_budget: self.over,
        }
    }
}

/// A running world: its thread, and its services task.
pub struct RunningWorld {
    handle: WorldHandle,
    thread: std::thread::JoinHandle<()>,
    services: tokio::task::JoinHandle<()>,
    stats: Arc<Mutex<Stats>>,
}

/// Starts the world's thread and its services task, on the current tokio runtime.
pub fn start(rules: Rules, store: Store) -> anyhow::Result<RunningWorld> {
    let (tx, rx) = mpsc::unbounded_channel();
    let (services_tx, services_rx) = mpsc::unbounded_channel();
    let hz = rules.tick_hz.max(1);
    let tick = Duration::from_secs(1) / hz;
    let stats = Arc::new(Mutex::new(Stats::new(hz as usize * 60)));
    let core = WorldCore::new(rules, services_tx);
    let thread = std::thread::Builder::new()
        .name("fenji-world".into())
        .spawn({
            let stats = Arc::clone(&stats);
            move || run(core, rx, tick, &stats)
        })?;
    let services = tokio::spawn(super::services::run(store, services_rx));
    Ok(RunningWorld {
        handle: WorldHandle(tx),
        thread,
        services,
        stats,
    })
}

impl RunningWorld {
    pub fn handle(&self) -> WorldHandle {
        self.handle.clone()
    }

    pub fn report(&self) -> TickReport {
        self.stats
            .lock()
            .unwrap_or_else(|e| e.into_inner())
            .report()
    }

    /// Saves everyone and stops: the thread ends after its shutdown tick, and the services task
    /// once it has written the last saves (waiting at most [`SAVE_WAIT`]).
    pub async fn stop(self) {
        self.handle.send(WorldIn::Shutdown);
        let thread = self.thread;
        if !matches!(
            tokio::task::spawn_blocking(move || thread.join()).await,
            Ok(Ok(()))
        ) {
            tracing::error!("the world's thread panicked");
        }
        if tokio::time::timeout(SAVE_WAIT, self.services)
            .await
            .is_err()
        {
            tracing::error!("the world's last saves took over {SAVE_WAIT:?}");
        }
    }
}

/// The tick loop. It ends after the tick that takes `Shutdown`, which comes when the server stops
/// or when every handle has gone.
fn run(
    mut core: WorldCore,
    mut rx: mpsc::UnboundedReceiver<WorldIn>,
    tick: Duration,
    stats: &Mutex<Stats>,
) {
    let start = Instant::now();
    let mut next = start;
    loop {
        let mut inputs = Vec::new();
        let mut stopping = false;
        loop {
            match rx.try_recv() {
                Ok(WorldIn::Shutdown) | Err(TryRecvError::Disconnected) => {
                    inputs.push(WorldIn::Shutdown);
                    stopping = true;
                    break;
                }
                Ok(msg) => inputs.push(msg),
                Err(TryRecvError::Empty) => break,
            }
        }
        let began = Instant::now();
        let now_ms = u64::try_from(began.duration_since(start).as_millis()).unwrap_or(u64::MAX);
        let phases = core.step(now_ms, inputs);
        stats
            .lock()
            .unwrap_or_else(|e| e.into_inner())
            .record(began.elapsed(), &phases, tick);
        if stopping {
            return;
        }
        next += tick;
        let now = Instant::now();
        if next > now {
            std::thread::sleep(next - now);
        } else {
            // Behind: start again from now rather than run a burst of ticks to catch up.
            next = now;
        }
    }
}

//! Interest management (Fenji design spec §6.4; world spec §3.3): a grid of 5,000-unit cells (50 m
//! if the units are centimetres), where each player sees the players in their own cell and the
//! eight around it, in the same scene. A player coming into view is announced (6); the client
//! pulls it (5), and the world sends it whole (7). Going out of view, or out of the game, is 9.
use std::collections::btree_map::Entry;
use std::collections::{BTreeMap, BTreeSet, HashMap};

use bevy_ecs::prelude::*;

use super::ecs::{Actor, Conn, Doomed, Here, Index, Pending, Stage, deliver};
use super::types::*;

/// A cell's side, in the client's units (world spec §3.3).
pub const CELL: f64 = 5_000.0;

/// A cell: the scene, then x and y counted in cells. z is up and doesn't count.
pub type Cell = (i64, i64, i64);

pub fn cell(at: &Location) -> Cell {
    (
        at.scene,
        (at.pos.x / CELL).floor() as i64,
        (at.pos.y / CELL).floor() as i64,
    )
}

/// How far a client has been told of another player.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Seen {
    /// Announced (6), not yet pulled.
    Announced,
    /// Sent whole (7), after the client's pull.
    Entered,
}

/// The players a player's client knows of.
#[derive(Component, Debug, Default)]
pub struct Sight(pub BTreeMap<ActorId, Seen>);

/// A player as a viewer: who, where, whether loaded, its connection, and what it knows of.
type Viewer = (
    Entity,
    &'static Actor,
    &'static Here,
    &'static Stage,
    &'static Conn,
    &'static mut Sight,
);

/// Each tick: tells every player in the world of the players coming into and going out of its
/// view, then answers the pulls. Players still loading neither see nor are seen, since the client
/// drops actors announced before its own (world spec §2.2).
pub(super) fn system(
    mut viewers: Query<Viewer, Without<Doomed>>,
    others: Query<(&Actor, &Here, &Stage), Without<Doomed>>,
    index: Res<Index>,
    mut pending: ResMut<Pending>,
    mut commands: Commands,
) {
    let mut grid: HashMap<Cell, Vec<ActorId>> = HashMap::new();
    let mut spots: HashMap<ActorId, Pos> = HashMap::new();
    for (actor, here, stage) in &others {
        if *stage == Stage::InWorld {
            grid.entry(cell(&here.0)).or_default().push(actor.pid);
            spots.insert(actor.pid, here.0.pos);
        }
    }
    for (e, actor, here, stage, conn, mut sight) in &mut viewers {
        if *stage != Stage::InWorld {
            continue;
        }
        let (scene, cx, cy) = cell(&here.0);
        let mut view = BTreeSet::new();
        for dx in -1..=1 {
            for dy in -1..=1 {
                if let Some(pids) = grid.get(&(scene, cx + dx, cy + dy)) {
                    view.extend(pids.iter().copied());
                }
            }
        }
        view.remove(&actor.pid);
        let gone: Vec<ActorId> = sight
            .0
            .keys()
            .filter(|pid| !view.contains(pid))
            .copied()
            .collect();
        if !gone.is_empty() {
            for pid in &gone {
                sight.0.remove(pid);
            }
            deliver(conn, e, WorldOut::Leave { pids: gone }, &mut commands);
        }
        for pid in view {
            if let Entry::Vacant(slot) = sight.0.entry(pid) {
                slot.insert(Seen::Announced);
                let pos = spots[&pid];
                deliver(conn, e, WorldOut::Announce { pid, pos }, &mut commands);
            }
        }

## Task 6 [cloud]: Movement: the speed rule and relays

Fenji design spec §6.4's lenient check, and world spec §3.4.
- A move passes when the distance it covers fits a budget.

//! The speed check (Fenji design spec §6.4; world spec §3.4), lenient by design. A move passes
//! when the distance it covers fits a budget that fills at the mover's top speed times the
//! tolerance and holds at most a second of it, so a burst after a network stall passes too.
//! Horizontal distance and climbing count; falling doesn't, so drops and glides pass. A move that
//! passes goes to whoever has the mover in view; one that doesn't is answered with where the mover
//! stands (20).
use bevy_ecs::prelude::*;

use super::ecs::{Actor, Conn, Doomed, Here, Now, Pending, Rules, Stage, deliver};
use super::interest::{Seen, Sight};
use super::types::*;

/// Units per second at speed rate 100 (world spec §2.3: about 500 cm/s).
pub const RUN: f64 = 500.0;
/// Sprinting and gliding add 70% (world spec §2.3).
pub const SPRINT: f64 = 1.7;
/// The highest speed rate the client allows (world spec §2.3).
pub const MAX_RATE: i64 = 340;
/// The farthest a coordinate may be from 0: 100 km.
pub const LIMIT: f64 = 10_000_000.0;
/// The largest yaw, either way, in degrees.
pub const YAW_LIMIT: f64 = 360.0;
/// The most movement a player can save up, in seconds.
pub const BURST_SECS: f64 = 1.0;

/// The fastest a player at speed `rate` may go, in units per second. The check doesn't know the
/// mode, so this is the sprint.
pub fn top_speed(rate: i64) -> f64 {
    rate.clamp(0, MAX_RATE) as f64 / 100.0 * RUN * SPRINT
}

/// A point the world takes: finite, within [`LIMIT`], with a yaw within [`YAW_LIMIT`].
pub fn valid(p: &Pos) -> bool {
    [p.x, p.y, p.z]
        .iter()
        .all(|v| v.is_finite() && v.abs() <= LIMIT)
        && p.yaw.is_finite()
        && p.yaw.abs() <= YAW_LIMIT
}

/// A player's movement budget.
#[derive(Component, Debug, Clone, Copy)]
pub struct Gait {
    budget: f64,
    at_ms: u64,
}

impl Gait {
    /// An empty budget that starts filling at `now_ms`.
    pub fn new(now_ms: u64) -> Self {
        Self {
            budget: 0.0,
            at_ms: now_ms,
        }
    }

    /// Whether a move from `from` to `to` at `now_ms` fits the budget. One that does spends it.
    pub fn check(&mut self, from: &Pos, to: &Pos, now_ms: u64, rate: i64, tolerance: f64) -> bool {
        if !valid(to) {
            return false;
        }
        let per_sec = top_speed(rate) * tolerance;
        let elapsed = now_ms.saturating_sub(self.at_ms) as f64 / 1000.0;
        self.at_ms = self.at_ms.max(now_ms);
        self.budget = (self.budget + per_sec * elapsed).min(per_sec * BURST_SECS);
        let climb = (to.z - from.z).max(0.0);
        let d = (to.x - from.x).hypot(to.y - from.y).hypot(climb);
        if d <= self.budget {
            self.budget -= d;
            true
        } else {
            false
        }
    }
}

/// Applies the tick's moves in order. Players still loading can't move.
pub(super) fn system(
    now: Res<Now>,
    rules: Res<Rules>,
    mut pending: ResMut<Pending>,
    mut movers: Query<(&Actor, &mut Here, &mut Gait, &Stage, &Conn), Without<Doomed>>,
    viewers: Query<(Entity, &Sight, &Conn), Without<Doomed>>,
    mut commands: Commands,
) {
    for (e, step) in std::mem::take(&mut pending.moves) {
        let Ok((actor, mut here, mut gait, stage, conn)) = movers.get_mut(e) else {
            continue;
        };
        if *stage != Stage::InWorld {
            continue;
        }
        let from = here.0.pos;
        if !gait.check(&from, &step.pos, now.0, SPEED_RATE, rules.move_tolerance) {
            deliver(conn, e, WorldOut::Correct { pos: from }, &mut commands);
            continue;
        }
        here.0.pos = step.pos;
        for (v, sight, to) in &viewers {
            if sight.0.get(&actor.pid) == Some(&Seen::Entered) {
                let msg = WorldOut::Moved {
                    pid: actor.pid,
                    step: step.clone(),
                };
                deliver(to, v, msg, &mut commands);
            }
        }
    }
}

//! Text the server passes on for others to see: chat lines, announcements and command arguments.

/// Characters that show nothing but change how the text around them shows: controls, the
/// bidirectional overrides and isolates, zero-width characters and the line separators. In a line
/// of chat or a command they could make it read as something else, in players' clients or in a
/// host's terminal.
pub fn hidden(c: char) -> bool {

        || matches!(

            '\u{061C}'

                | '\u{2028}'..='\u{202E}'
                | '\u{2060}'..='\u{2064}'
                | '\u{2066}'..='\u{2069}'
                | '\u{FEFF}'
                | '\u{FFF9}'..='\u{FFFB}'
        )
}

//! Chat (world spec §3.5): nearby to whoever sees the speaker, world to everyone in the game, and
//! whispers to their target by pid or by name. Every line is echoed to its speaker too, since the
//! client shows nothing of its own. The server enforces the client's own limits again, and a rate
//! (world spec §2.4).
use bevy_ecs::prelude::*;

use super::ecs::{Actor, Conn, Doomed, Index, Now, Pending, Stage, deliver, name_key};
use super::interest::Sight;
use super::types::*;
use crate::text::plain;

/// The most characters in a line, as the client counts them.
pub const MAX_CHARS: usize = 140;
/// The most bytes in a line as it arrives, after the client's own escaping.
pub const MAX_BYTES: usize = 2048;
/// The rate: a burst of this many lines…
pub const BURST: f64 = 5.0;
/// …then this many a second.
pub const PER_SEC: f64 = 1.0;

/// The entities the client's input writes, for `&`, `<` and `>`; it writes no others.
const ENTITIES: [&str; 3] = ["&amp;", "&lt;", "&gt;"];

/// Whether `text` has anything a client might read as markup:
/// - an `&` that doesn't start one of [`ENTITIES`], which might decode to a tag;
/// - a `\\`, which link escapes start with;
/// - a `[` whose next character, past any spaces, isn't a digit or `]`: the client renders
///   `[link …]`, `[q_sound …]`, `[duration …]` and `[teamshout]`, which could forge a sender, a
///   link or a sound in other players' clients.
///
/// The client's own input escapes `&`, `<` and `>` and builds links itself, so a player typing
/// loses only words in square brackets and backslashes.
fn markup(text: &str) -> bool {
    let stray = text
        .match_indices('&')
        .any(|(i, _)| !ENTITIES.iter().any(|e| text[i..].starts_with(e)));
    if stray || text.contains('\\') {
        return true;
    }
    let mut open = false;
    for c in text.chars() {
        if open && !c.is_whitespace() {
            if !(c.is_ascii_digit() || c == ']') {
                return true;
            }
            open = false;
        }
        if c == '[' {
            open = true;
        }
    }
    false
}

/// A line's length as the client counts it: characters, with each entity its input writes for
/// `&`, `<` and `>` counted as one.
pub fn length(text: &str) -> usize {
    text.replace("&lt;", "<")
        .replace("&gt;", ">")
        .replace("&amp;", "&")
        .chars()
        .count()
}

/// Whether the server takes a line's text.
pub fn check(text: &str) -> Result<(), ChatRefusal> {
    if text.trim().is_empty() || !plain(text) || text.contains(['<', '>']) || markup(text) {
        return Err(ChatRefusal::Invalid);
    }
    if length(text) > MAX_CHARS || text.len() > MAX_BYTES {
        return Err(ChatRefusal::TooLong);
    }
    Ok(())
}

/// A player's chat allowance: a token bucket.
#[derive(Component, Debug, Clone, Copy)]
pub struct Bucket {
    tokens: f64,
    at_ms: u64,
}

impl Bucket {
    /// A full bucket at `now_ms`.
    pub fn new(now_ms: u64) -> Self {
        Self {
            tokens: BURST,
            at_ms: now_ms,
        }
    }

    /// Takes a line's token at `now_ms`, if there is one.
    pub fn take(&mut self, now_ms: u64) -> bool {
        let elapsed = now_ms.saturating_sub(self.at_ms) as f64 / 1000.0;
        self.at_ms = self.at_ms.max(now_ms);
        self.tokens = (self.tokens + elapsed * PER_SEC).min(BURST);
        if self.tokens >= 1.0 {
            self.tokens -= 1.0;
            true
        } else {
            false
        }
    }
}

/// Routes the tick's lines.
pub(super) fn system(
    now: Res<Now>,
    index: Res<Index>,
    mut pending: ResMut<Pending>,
    mut speakers: Query<(&Actor, &Stage, &mut Bucket, &Conn), Without<Doomed>>,
    listeners: Query<(Entity, &Actor, &Sight, &Conn), Without<Doomed>>,
    mut commands: Commands,
) {
    for (e, line) in std::mem::take(&mut pending.lines) {
        let Ok((actor, stage, mut bucket, conn)) = speakers.get_mut(e) else {
            continue;
        };
        if *stage != Stage::InWorld {
            continue;
        }
        let refused = if !bucket.take(now.0) {
            Some(ChatRefusal::TooFast)
        } else {
            check(&line.text).err()
        };
        if let Some(why) = refused {
            deliver(conn, e, WorldOut::ChatRefused(why), &mut commands);
            continue;
        }
        let from = Speaker {
            pid: actor.pid,
            name: actor.look.name.clone(),
            vocation: actor.look.vocation,
        };
        match line.channel {
            ChatChannel::Nearby => {
                let said = WorldOut::Chat(ChatOut::Said {
                    channel: ChatChannel::Nearby,
                    from,
                    to: None,
                    text: line.text,
                });
                deliver(conn, e, said.clone(), &mut commands);
                for (v, _, sight, to) in &listeners {
                    if v != e && sight.0.contains_key(&actor.pid) {
                        deliver(to, v, said.clone(), &mut commands);
                    }
                }
            }
            ChatChannel::World => {
                let said = WorldOut::Chat(ChatOut::Said {
                    channel: ChatChannel::World,
                    from,
                    to: None,
                    text: line.text,
                });
                for (v, _, _, to) in &listeners {
                    deliver(to, v, said.clone(), &mut commands);
                }
            }
            ChatChannel::Whisper => {
                let target = match &line.to {
                    Some(WhisperTarget::Pid(pid)) => index.pids.get(pid).copied(),
                    Some(WhisperTarget::Name(name)) => {
                        // A typed name comes as `Name@<server>`; the server part is the client's.
                        let name = name.split('@').next().unwrap_or_default().trim();
                        index.names.get(&name_key(name)).copied()
                    }
                    None => None,
                };
                let Some(t) = target else {
                    let refused = WorldOut::ChatRefused(ChatRefusal::NotOnline);
                    deliver(conn, e, refused, &mut commands);
                    continue;
                };
                if t == e {
                    let refused = WorldOut::ChatRefused(ChatRefusal::ToSelf);
                    deliver(conn, e, refused, &mut commands);
                    continue;
                }
                let Ok((_, target, _, to)) = listeners.get(t) else {
                    let refused = WorldOut::ChatRefused(ChatRefusal::NotOnline);
                    deliver(conn, e, refused, &mut commands);
                    continue;
                };
                let said = WorldOut::Chat(ChatOut::Said {
                    channel: ChatChannel::Whisper,
                    from,
                    to: Some(Speaker {
                        pid: target.pid,
                        name: target.look.name.clone(),
                        vocation: target.look.vocation,
                    }),
                    text: line.text,
                });
                deliver(to, t, said.clone(), &mut commands);
                deliver(conn, e, said, &mut commands);
            }
        }
    }
}

//! The admin command set (M4 spec §4.3): one module for the game's chat, where admins
//! (`[access].admins`) type a command after `!`, and for the host console, which hosting adds,
//! with the same names and arguments.
use std::fmt;

/// An admin command.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Command {
    /// `tp <name>` takes the admin to a player; `tp <name> <name>` takes the first to the second.
    Tp { who: Option<String>, to: String },
    /// `kick <name>`.
    Kick { name: String },
    /// `announce <text>`: the marquee, for everyone in the game.
    Announce { text: String },
    /// `invite [label]`: a new invite link.
    Invite { label: Option<String> },
}

/// Why a line isn't a command that can run.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum CommandError {
    Unknown(String),
    Usage(&'static str),
    /// Controls or invisible formatting ([`crate::text::hidden`]): a label or an announcement
    /// shows them to everyone, and `invite list` to the host's terminal.
    NotPlain,
}

pub const TP: &str = "tp <name> [<name>]";
pub const KICK: &str = "kick <name>";
pub const ANNOUNCE: &str = "announce <text>";
pub const INVITE: &str = "invite [label of at most 64 characters]";

/// The longest invite label.
pub const LABEL_MAX: usize = 64;

impl fmt::Display for CommandError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::Unknown(word) => {
                write!(
                    f,
                    "no command {word}; the commands are tp, kick, announce and invite"
                )
            }
            Self::Usage(usage) => write!(f, "usage: {usage}"),
            Self::NotPlain => write!(f, "commands take plain text only"),
        }
    }
}

/// Parses a command, without its `!`.
pub fn parse(line: &str) -> Result<Command, CommandError> {
    if !crate::text::plain(line) {
        return Err(CommandError::NotPlain);
    }
    let line = line.trim();
    let (word, rest) = match line.split_once(char::is_whitespace) {
        Some((word, rest)) => (word, rest.trim()),
        None => (line, ""),
    };
    let args: Vec<&str> = rest.split_whitespace().collect();
    match word.to_ascii_lowercase().as_str() {
        "tp" => match args.as_slice() {
            [to] => Ok(Command::Tp {
                who: None,
                to: (*to).into(),
            }),
            [who, to] => Ok(Command::Tp {
                who: Some((*who).into()),
                to: (*to).into(),
            }),
            _ => Err(CommandError::Usage(TP)),
        },
        "kick" => match args.as_slice() {
            [name] => Ok(Command::Kick {
                name: (*name).into(),
            }),
            _ => Err(CommandError::Usage(KICK)),
        },
        "announce" if !rest.is_empty() => Ok(Command::Announce { text: rest.into() }),
        "announce" => Err(CommandError::Usage(ANNOUNCE)),
        "invite" if rest.chars().count() > LABEL_MAX => Err(CommandError::Usage(INVITE)),
        "invite" => Ok(Command::Invite {
            label: (!rest.is_empty()).then(|| rest.into()),
        }),
        _ => Err(CommandError::Unknown(word.into())),
    }
}

/// A chat line as a command: `Some` when it starts with `!` and a letter, `None` for any other
/// line, which is plain chat even from an admin.
pub fn from_chat(text: &str) -> Option<Result<Command, CommandError>> {
    let rest = text.strip_prefix('!')?;
    rest.starts_with(|c: char| c.is_ascii_alphabetic())
        .then(|| parse(rest))
}

//! Admin commands in the game (world spec §3.6): what `!tp`, `!kick`, `!announce` and `!invite`
//! do. The chat phase parses an admin's `!` line with [`crate::commands`] and queues it here; the
//! answer is a line only the admin sees.
use bevy_ecs::prelude::*;

use super::chat;
use super::ecs::{
    Actor, Conn, Doomed, Here, Index, Now, Pending, Services, Stage, doom, hide, name_key, send,
};
use super::interest::Sight;
use super::movement::Gait;
use super::types::*;
use crate::commands::Command;

/// Runs the tick's commands, in order.
pub(super) fn system(world: &mut World) {
    for (admin, order) in std::mem::take(&mut world.resource_mut::<Pending>().orders) {
        if world.get::<Doomed>(admin).is_some() {
            continue;
        }
        if let Some(text) = run(world, admin, order) {
            send(world, admin, WorldOut::Chat(ChatOut::System { text }));
        }
    }
}

/// Does `order` for `admin`, and returns the answer, if there is one now.
fn run(world: &mut World, admin: Entity, order: Command) -> Option<String> {
    match order {
        Command::Tp { who, to } => {
            let mover = match &who {
                Some(name) => find(world, name),
                None => Some(admin),
            };
            let Some(mover) = mover else {
                return Some(absent(who.as_deref().unwrap_or_default()));
            };
            let Some(target) = find(world, &to) else {
                return Some(absent(&to));
            };
            if mover == target {
                return Some(format!("{} is already there", name_of(world, mover)));
            }
            let at = world.get::<Here>(target)?.0;
            teleport(world, mover, at);
            Some(format!(
                "{} is with {}",
                name_of(world, mover),
                name_of(world, target)
            ))
        }
        Command::Kick { name } => {
            let Some(e) = find(world, &name) else {
                return Some(absent(&name));
            };
            doom(world, e, Some(KickReason::Kicked));
            Some(format!("{} was kicked", name_of(world, e)))
        }
        Command::Announce { text } => {
            if let Err(why) = chat::check(&text) {
                return Some(match why {
                    ChatRefusal::TooLong => "not announced: over 140 characters".into(),
                    _ => "not announced: control characters or markup".into(),
                });
            }
            let everyone: Vec<Entity> = world.resource::<Index>().conns.values().copied().collect();
            for e in everyone {
                let text = text.clone();
                send(world, e, WorldOut::Chat(ChatOut::Announce { text }));
            }
            None
        }
        Command::Invite { label } => {
            let conn = world.get::<Conn>(admin)?.id;
            let _ = world
                .resource::<Services>()
                .0
                .send(Service::CreateInvite { conn, label });
            None
        }
    }
}

/// The player called `name` (any ASCII case), unless it leaves this tick.
fn find(world: &World, name: &str) -> Option<Entity> {
    let e = *world.resource::<Index>().names.get(&name_key(name))?;
    world.get::<Doomed>(e).is_none().then_some(e)
}

fn name_of(world: &World, e: Entity) -> String {
    world
        .get::<Actor>(e)
        .map(|a| a.look.name.clone())
        .unwrap_or_default()
}

fn absent(name: &str) -> String {
    format!("no one called {name} is in the game")
}

/// Moves `e` to `at`. Its viewers forget it, and see it again where it lands at their next
/// interest pass. Within its scene it is moved (`Teleport`); another scene is loaded as on
/// entering.
fn teleport(world: &mut World, e: Entity, at: Location) {
    let now = world.resource::<Now>().0;
    let (Some(actor), Some(here), Some(stage)) = (
        world.get::<Actor>(e),
        world.get::<Here>(e),
        world.get::<Stage>(e),
    ) else {
        return;
    };
    let (pid, same_scene) = (actor.pid, here.0.scene == at.scene);
    let in_world = *stage == Stage::InWorld;
    hide(world, pid);
    if let Some(mut here) = world.get_mut::<Here>(e) {
        here.0 = at;
    }
    if let Some(mut gait) = world.get_mut::<Gait>(e) {
        *gait = Gait::new(now);
    }
    if same_scene && in_world {
        send(world, e, WorldOut::Teleport { pos: at.pos });
        return;
    }
    if let Some(mut stage) = world.get_mut::<Stage>(e) {
        *stage = Stage::Loading;
    }
    if let Some(mut sight) = world.get_mut::<Sight>(e) {
        sight.0.clear();
    }
    send(world, e, WorldOut::LoadScene { pid, at });
}

## The local slices (Tasks 10–16): how they fit together

World spec §4.1's four vertical slices, each in four steps: read in the exe, write it up, build test-first, and run with the real client.
- The readings (10, 12, 14) and slice 4's reading part (16) write `docs/protocol/` and an Amendment.
- The builds (11, 13, 15, 16) carry the amendments out on top of the cloud tasks' world.

Two pieces of code belong to the slices and grow across them:
- `crates/fenji-proto/src/world.rs`: the world's codecs, sans-I/O like the rest of `fenji-proto`. Each codec carries its evidence in its doc comment and has golden tests.
- `crates/fenji-server/src/link.rs`: a connection in the world. It takes over the gate's connection when the client sends 10. It maps the client's messages to `WorldIn`, and `WorldOut` back to messages, and ends with `WorldIn::Leave`.

**The link's shape** (Task 11 writes it; the later slices add mappings). It is a function the gate calls in place of the lobby loop:

```rust
/// Plays `character` in the world on the gate's connection, until the client leaves, the world
/// lets go of it, or a newer login replaces it.
pub(crate) async fn play(
    sock: &mut TcpStream,
    peer: SocketAddr,
    gate: &Gate,
    server: &mut Server,
    account: &Account,
    conn: ConnId,
    character: Character,
    replaced: &mut oneshot::Receiver<()>,
) -> anyhow::Result<()>
```

It works like this:
- **Setting up.**
  - It makes a bounded channel of `OUTBOUND = 256` messages.
  - It builds the `Player`:
    - the look comes from the character;
    - `admin` is true when `[access].admins` names the account, without regard to ASCII case;
    - `at` is the character's place, or `world::start_location`.
  - It sends `WorldIn::Join`. If the world has stopped, it answers 270 `SERVER_NOT_RESP` and ends.
- **Leaving.** A guard sends `WorldIn::Leave { conn }` when the function returns, however it returns, a panic included (Review Focus 1).
- **The loop.** It `select!`s over three things:
  - **The socket's frames,** with the gate's idle deadline:
    - script 392 (`CLIENT_EXIT`) ends the session;
    - native type 2 is answered at once with the time sync;
    - the slices add the rest, mapped to `WorldIn`.
  - **The world's channel.**
    - Each `WorldOut` is encoded and written within the gate's write deadline. A client that stops reading is closed: Review Focus 5's second half; the first is the world's own kick.
    - `None` means the world has let go: close.
  - **`replaced`,** which closes through Task 9a's `close_replaced`.
- **`WorldOut::Kicked(reason)`** closes with a reason the client shows:
  - `Replaced`: `DUPLICATE_LOGIN`;
  - `Shutdown` and `Kicked`: keys chosen from the client's close-reason table by the slice's reading;
  - `SlowReader` and `Flood`: no reason.

**The gate's side** (Task 11):
- `on_message` turns `SELECT_ACTOR` (10) into `Step::Enter(pid)`.
- The lobby loop then checks the character with `store.character(account.id, pid)`:
  - if it belongs to the account, the lobby loop calls `link::play` and returns when it does;
  - if not, it answers 270 `ROLE_NOT_FOUND` and stays in the lobby.
- `Gate` gains `world: WorldHandle`, `start: Location` and `admins: Vec<String>` (lower-case). `server::start` fills them in.
