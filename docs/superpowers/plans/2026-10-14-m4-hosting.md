# M4 Hosting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Anyone can host a Fenji server for invited friends: a console in the terminal (in its own window, as plain lines, or attached to a service), maintenance mode, the server's facts for launchers, TLS without a domain, backups, a first run that writes its own config, release archives with start scripts, and a write-up for hosts.

**Architecture:** One console service inside `fenji-server` runs commands and streams the log and the server's status. A new crate, `fenji-console`, holds the wire protocol and the two front ends (full-screen with `ratatui`, and plain lines); the server uses it in-process and over a Unix socket. The account API gains maintenance, server facts, an online list and an optional TLS mode with the server's own key, which invite links pin and `fenji-launcher` checks.

**Tech Stack:** Rust 1.97.1 (edition 2024), tokio, axum 0.8, sqlx 0.9 (SQLite), bevy_ecs, ratatui 0.30 and crossterm 0.29, rustls 0.23 with `ring`, tokio-rustls 0.26, rcgen, tracing-appender 0.2, GitHub Actions, systemd, Caddy 2.11.

**Spec:** [`docs/superpowers/specs/2026-10-14-m4-hosting-design.md`](../specs/2026-10-14-m4-hosting-design.md) (merged as d2f13f5, #245), under the [M4 umbrella spec](../specs/2026-10-13-m4-social-sandbox-design.md) §3.2 and §4. Written and approved under the owner's pre-approval of 2026-10-14 night.

## Global Constraints

- **Ground rules** (CLAUDE.md). Every task here is repository-only: nothing from `re/`, the game client or its files.
- **No outbound calls.** The server and the console make no network connection of their own: no telemetry, no update check, no "what is my IP" service.
- **Dependencies.** Only these are new, each under `deny.toml`'s licences: `ratatui` 0.30 and `crossterm` 0.29 (feature `event-stream`), plus `futures-util` for `StreamExt` if not already in the graph, in `fenji-console`; `tokio-rustls` 0.26, `rcgen` (feature `ring`, no `aws_lc_rs`) and `tracing-appender` 0.2 in `fenji-server`. `rustls` 0.23 with `ring` is already a workspace dependency. Add each to `[workspace.dependencies]` at its newest stable patch, and confirm its API with context7 before use.
- **The gate:** `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace && cargo deny check`, then `scripts/check-forbidden-files.sh`, before every pull request.
- **Commits and PRs.** Conventional Commits, scopes from `docs/development.md`, subjects of at most 100 characters and PR titles of at most 93. Each commit ends with exactly one trailer, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never a `Claude-Session:` line or a session URL. PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)` and carry `Closes #<task issue>`. Stage by path; never `git add -A`.
- **Exact values** (spec §3):

  | Longest console line, either way | 4,096 bytes |
  | Log backlog sent at attach | 500 lines |

- **Colours** (spec §3.2): ink-950 `#0c0c0f`, ink-900 `#111115`, ink-850 `#16161b`, ink-800 `#1c1c22`, text `#f2efe9`, text-2 `#c9c2b7`, muted `#a8a196`, faint `#8c867c`, gold-300 `#f2b365`, ok `#7fd38f`, warn `#e8b04a`, danger `#f26d7d`.
- **Players' text is untrusted.** Names, chat, invite labels and messages reach the host's terminal. Every string the console draws or prints, and every log line written to a file or to stderr, goes through one function, `fenji_console::text::clean`, which shows hidden characters as escapes (Task 6).
- **Order (spec H13).** Task 9 changes the world's behaviour and starts only after the M4 world plan's Task 16 has merged into `dev`. Task 4 changes only the type `invite_base` travels in through `world/thread.rs` and `world/services.rs` (Ruling HP1), which H13 doesn't hold.

## Review Focus

The inputs and failures the spec implies that a host or player would hit first, each pinned by a test in the task that owns the code:
1. **Escapes in players' text reaching the host's terminal.** A character name, chat line or invite label carrying `ESC`, other controls or bidirectional overrides must show as visible escapes in the console, the plain output and the log file, never act on the terminal. Tasks 6 and 7.
2. **The terminal given back on every exit.** After `stop`, Ctrl-C, SIGTERM, an error or a panic, the host's terminal is back on the main screen, in cooked mode, with a cursor. Tasks 6 and 10.
3. **TLS handshakes that never finish.** Idle or slow connections to the TLS port must not keep other players from the account API: handshakes run concurrently, each within its time limit, and a bounded number at once. Task 4.
4. **Maintenance holding every way in.** Sign-in, game tickets and invite redemption all refuse during maintenance, and an admin is exempt by the account that signed in, not by a name in a request. Task 3.
5. **Two servers on one data folder.** A second server started on the same data folder must refuse before it opens the database or binds a port. Task 11.

## Rulings made while planning

- **HP1:** Task 4 changes `invite_base`'s type in `world/thread.rs` and `world/services.rs` from `Option<String>` to `Option<InviteBase>`, so a link can carry its pin. That's a signature, not world behaviour, so H13 doesn't hold it — cost if wrong: one trivial rebase for the world plan's Task 16.
- **HP2:** The pin is the SubjectPublicKeyInfo's hash (spec §3.10), computed on both sides with `rustls::server::ParsedCertificate::subject_public_key_info`, so no X.509 parser is added — cost if wrong: none.
- **HP3:** `fenji_server::text`'s `hidden`, `plain` and `escape_hidden` move to `fenji_console::text`, which `fenji_server::text` re-exports, so the server's checks and the console's `clean` are one list — cost if wrong: one module moved back.
- **HP4:** The release workflow also runs on pull requests that change it, its packaging script or the start scripts, building everything without publishing: a workflow can't be dispatched by hand until it's on the default branch — cost if wrong: one trigger.
- **HP5:** The backup verifies its copy (`PRAGMA integrity_check`) before it prunes older copies, so a bad copy never costs a good one — cost if wrong: one query per backup.
- **HP6:** The console shows times in UTC, as the CLI's `invite list` already does. Local time needs a time-zone crate, and tests stay the same on every machine — cost if wrong: a time-zone dependency later.

**Order:** Tasks 1 to 8, then 12, can run as soon as a slot is free. Task 9 waits for the world plan's Task 16 (H13), and Tasks 10, 11 and 13 follow it in that order. Task 14 comes last.

    assert!(held[0].until_bye().await.contains("line too long"));
}
